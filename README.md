# PDC — сайт-визитка

Сайт с информацией о **Personal Data Cleaner (PDC)** для пользователей: возможности
PDC.Desktop и PDC.Server, пример обработки, требования, частые вопросы.
Публикуется на GitHub Pages: **https://a0nikolaev.github.io/pdc/** (`/ru/`, `/en/`, `/kk/`, `/uz/`, `/ky/`, `/tg/`; корень
учитывает сохранённый выбор и языки браузера).

Контакт по вопросам о PDC: a0nikolaevsoft@gmail.com.

## Устройство

- [Astro](https://astro.build) 5, статическая сборка; тексты RU/EN —
  `src/i18n/content.ts`, разметка — `src/components/Landing.astro`, стили —
  `src/styles/global.css` (тёмная тема по умолчанию и светлая тема; переключатель рядом с языком, выбор сохраняется в браузере).
- Изображения — `public/img/`: карусель содержит пять экранов PDC.Desktop на каждом языке.
  Снимки интерфейса подготовлены из сборки приложения с изолированным демонстрационным
  HTTP-транспортом и отдельными настройками, без подключения к реальному серверу.
  Пример «до/после» сделан на
  тестовых документах с **вымышленными** данными. Реальные документы и персональные данные
  на сайт не попадают.
- Публикация — `.github/workflows/deploy.yml` (официальный `withastro/action`) при каждом
  push в `main`.

- Анимированный фон показывает превращение условных персональных данных в метки;
  есть пауза и поддержка системной настройки уменьшения движения.

## Локально

```bash
npm install
npm run dev      # http://localhost:4321/pdc/
npm run build    # результат — dist/
```

Без установленного Node.js — в контейнере:

```bash
docker run --rm -it -p 4321:4321 -v "$PWD:/site" -w /site node:22 bash -c "npm install && npm run dev"
```

## История изменений

Страницы `/pdc/ru/changelog/` и `/pdc/en/changelog/` доступны по ссылке
«Обновления» / «Updates» в шапке. Карточки содержат основные изменения по патчам,
а фильтры позволяют отдельно смотреть desktop и сервер. Без JavaScript видны
все релизы. При смене языка сохраняется раздел; тема общая с главной страницей.

Данные `src/data/releases.json` включены в репозиторий: сборка сайта не требует
доступа к исходникам продукта. Для обновления после релиза:

```bash
npm run sync:releases
# Если продукт находится не в соседнем personal-data-cleaner:
npm run sync:releases -- C:/repos/personal-data-cleaner
npm run build
```

Скрипт берёт согласованные основные изменения RU/EN из ресурсов desktop
(`Changelog.DesktopHistory`, `Changelog.ServerHistory`) и проверяет наличие
каждой версии в соответствующем `change_log/CHANGELOG*.md` основного проекта.
После синхронизации закоммитить обновлённый JSON. Запланированные задачи
в историю выпущенных версий не попадают.

## Первая публикация

1. Создать **публичный** репозиторий `a0nikolaev/pdc` на GitHub (без README).
2. `git remote add origin https://github.com/a0nikolaev/pdc.git && git push -u origin main`
3. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
4. После первого запуска workflow сайт доступен по адресу выше.

## Для инвесторов

В шапке доступно меню скачивания PDF V3 RU/EN. Файлы находятся в
`public/downloads/`, атрибут `download` запускает сохранение файла.
При обновлении PDF заменить обе версии из `PDC/presentation/output/`,
обновить ссылки меню и убрать старые копии.

## Шесть языков сайта

Главная и changelog переведены на русский, английский, казахский (`kk`),
узбекский (`uz`), кыргызский (`ky`) и таджикский (`tg`). Выпадающий список
показывает названия языков на них самих. Переключение сохраняет страницу,
query-параметры и якорь; выбор запоминается в localStorage. На корневом URL
сначала используется сохранённый язык, затем первый поддерживаемый язык
браузера, иначе английский. Без JavaScript доступны ссылки на все языки.

Основные переводы — `src/i18n/locales/`, элементы управления и доступности —
`src/i18n/ui.json`, правила выбора — `src/i18n/languages.ts`. Лента переводится
через `src/data/release-translations.json`; сравнение с исходным текстом
останавливает сборку при пропущенном или устаревшем переводе записи.

Перевод сайта не добавляет новых языков распознавания в продукт. Подписи
скриншотов переведены; сами скриншоты сохраняют реальный RU/EN-интерфейс
приложения. PDF для инвесторов доступны на русском и английском V3.

Проверка на Node.js 22.18+ (проверено на bundled Node 24):

```bash
npm run build
npm run check
npm test
```

Проверяются типы, страницы/ссылки/ресурсы, полнота словарей и переводов
обновлений. Четыре unit-теста покрывают выбор языка. В Edge проверены
36 сочетаний: 6 языков × главная/changelog × 320/375/1280px; скачивания,
фильтры, клавиатура, сохранение страницы/языка, редирект корня, no-JS и
светлая тема. Ошибок JavaScript и горизонтального скролла нет.

## PDC.Web на сайте

Раздел PDC.Web и пункт «Клиент у сотрудников» описывают встроенный
браузерный интерфейс сервера `/web/`, без установки Desktop. Тексты всех
шести языков находятся в `src/i18n/web.json`. Описаны файлы, пакеты, шаблоны,
режимы замены, профили/оформление и доступ по ролям.

`ProductGallery.astro` обслуживает обе независимые галереи: Desktop и Web.
У каждой свой track ID, счётчик, стрелки, подписи, клавиатура и fullscreen.
Скриншоты Web — `public/img/web-{ru,en}-{anonymize,batch,placeholders,modes,settings}.png`.
На новых языках сайта показан реальный EN-интерфейс приложения с переведёнными
подписями, как и для Desktop; новые языки приложения не заявляются.

Снимки получены из неизменённых локальных файлов PDC.Web с синтетическими
ответами API. Все запросы перехвачены в изолированном браузере, реальный
сервер, база, модели и документы не использовались. Демонстрационные числа
замен/состояния не являются результатами измерения. Источник, версии,
параметры и SHA-256 снимков/исходников: `docs/web-screenshots-provenance.json`.
Проверка контролирует соответствие снимков записанным контрольным суммам.

## Индексация

Сборка создаёт `/pdc/sitemap.xml` с 13 страницами, шестью языковыми
alternate-ссылками и x-default. `/pdc/robots.txt` содержит адрес sitemap.
На GitHub Pages project-site этот файл расположен в `/pdc/`; правила
robots для всего домена применяются из корня хоста и управляются отдельно.
Главные страницы и языковой выбор ссылаются x-default на корень проекта;
changelog — на английский changelog, чтобы сохранить смысл страницы.

## Навигация и доступность

На экранах до 760px доступно мобильное меню с семью разделами. Native
`details` работает без JavaScript; Escape, выбор раздела и щелчок вне меню
закрывают его при включённом JavaScript. Первая ссылка по Tab переводит
фокус к основному содержимому; подписи переведены на все шесть языков.
Отступ якорей учитывает фактическую высоту шапки. Системный режим уменьшения
движения отключает плавную прокрутку и фоновые анимации.

Изображения «до/после» открываются в диалоге, переключаются кнопками и
стрелками, закрываются Escape с возвратом фокуса. Без JavaScript открываются
исходные PNG. Реальные размеры изображений заданы в разметке и сверяются
с PNG-заголовками при проверке сайта.
